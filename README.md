# Glowfrog: privacy policy

This repository hosts the privacy policy for **Glowfrog**, a one-tap runner game for Even Realities G2 (Even Hub plug-in `io.github.jay22122.glowfrog`).

- Policy page: https://jay22122.github.io/glowfrog/
- Source text: [privacy-policy.md](privacy-policy.md)
- Questions or reports: [https://github.com/Jay22122/glowfrog/issues](https://github.com/Jay22122/glowfrog/issues)

Glowfrog collects no personal data, asks for no permissions and makes no network requests.
